A static scramjet implementation similar to /staticsj but now uses jsdelivr cdn's to significantly reduce the size of the codebase.

## Wisp endpoint
The built-in Wisp endpoint is set to `wss://wisp.mercurywork.shop`. If a browser has another custom Wisp URL saved in local storage, open the proxy settings and switch to MercuryWork, or clear this site's local storage to reset it.
